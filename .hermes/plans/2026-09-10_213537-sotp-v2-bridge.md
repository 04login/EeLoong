# Plan — Valuation Lab v2: part multipliers + equity bridge + balance-sheet prefill

**Verify when done: `npm test` (fail 0) + `npm run build` (exit 0) + dev curl smoke + browser click-through (Tasks 8–9).**

## Goal

Extend the Valuation Lab (v1 already shipped: manual SOTP with parts × user valuations, KV-persisted) with:
1. **Per-part valuation modes** — `manual` (absolute value, today's behavior) or `multiple` (an EV/Revenue multiple × that part's reference revenue; e.g. 8 × $7.55B → $60.4B). Seeded AX parts store their segment revenue as `revenueRef` so this is real math, not string-parsing.
2. **Equity bridge** — explicit input lines below the parts: net debt (negative = net cash), minority interests, redeemable preferred, SOTP discount %, illiquidity %. Formula: `equity = (partsTotal − netDebt − minorityInterests − preferred) × (1 − sotpDiscount%) × (1 − illiquidity%)`, then `perShare = equity / sharesOutstanding`.
3. **Prefill from balance sheet** — a button on the editor (shown when the model has `importedFrom.ticker`) that fetches the latest periodic filing's instance XML and fills **only empty** bridge fields + shares outstanding with computed values (netDebt, preferred, share count). Deterministic XBRL tag lookup — **no LLM call** in this plan's prefill path.

```ts
export type SotpBridge = {
  netDebt: number;           // + = subtract, − = net cash (adds)
  minorityInterests: number;
  preferred: number;
  sotpDiscountPct: number;   // whole % (10 = 10%), clamped 0–30
  illiquidityPct: number;    // whole %, clamped 0–60
};

const clampPct = (v: unknown, lo: number, hi: number): number =>
  typeof v === "number" && Number.isFinite(v) ? Math.min(Math.max(v, lo), hi) : 0;

export const computeBridge = (
  partsTotal: number,
  bridge: Partial<SotpBridge> | undefined,
  sharesOutstanding: number | null,
): {
  partsTotal: number;
  afterNetDebt: number;
  afterInterests: number;
  afterDiscount: number;
  equityValue: number;
  perShare: number | null;
} => {
  const netDebt = Number.isFinite(bridge?.netDebt) ? bridge.netDebt! : 0;
  const minority = Number.isFinite(bridge?.minorityInterests) ? bridge.minorityInterests! : 0;
  const preferred = Number.isFinite(bridge?.preferred) ? bridge.preferred! : 0;
  const afterNetDebt = partsTotal - netDebt;
  const afterInterests = afterNetDebt - minority - preferred;
  const sotpPct = clampPct(bridge?.sotpDiscountPct, 0, 30);
  const illiqPct = clampPct(bridge?.illiquidityPct, 0, 60);
  const afterDiscount = afterInterests * (1 - sotpPct / 100) * (1 - illiqPct / 100);
  return {
    partsTotal,
    afterNetDebt,
    afterInterests,
    afterDiscount,
    equityValue: afterDiscount,
    perShare: sharesOutstanding !== null && sharesOutstanding > 0 ? afterDiscount / sharesOutstanding : null,
  };
};
```

```ts
export type SotpPart = {
  label: string;
  valuation: number;
  note: string;
  mode?: "manual" | "multiple";    // absent = manual (backward compatible)
  revenueRef?: number | null;      // e.g. segment revenue backing a multiple
  multiple?: number;               // e.g. 8 → valuation = revenueRef × 8
};

export const recomputeMultiples = (parts: SotpPart[]): SotpPart[] =>
  parts.map((p) =>
    p.mode === "multiple" &&
    (p.multiple ?? 0) > 0 &&
    typeof p.revenueRef === "number" && Number.isFinite(p.revenueRef) && p.revenueRef !== 0
      ? { ...p, valuation: p.revenueRef * p.multiple! }
      : p,
  );
```

```ts
// Bridge prefetch — deterministic XBRL extraction of balance-sheet lines:
// netDebt = (debt current+noncurrent + finance leases) − cash − marketable sec;
// minority/preferred/shares copied when present. No LLM. Fills ONLY empty
// fields — never overwrites user input; returns which fields were filled.
export const prefillBridgeFromEdgar = async (
  env: SotpActionEnv,
  kv: KVNamespace | undefined,
  ticker: string,
): Promise<{ netDebt: number; minorityInterests: number; preferred: number; sharesOutstanding: number; period: string } | null> => {
  const cikInfo = await tickerToCik(ticker.trim().toUpperCase(), kv);
  if (!cikInfo) return null;
  const filing = await latestPeriodic(cikInfo.cik);
  if (!filing) return null;
  const facts = await fetchBalanceSheetFacts(filing);
  if (!facts) return null;
  const debt = (facts.totalDebt ?? 0) + (facts.financeLeases ?? 0);
  const cash = (facts.cash ?? 0) + (facts.marketableSec ?? 0);
  const netDebt = debt - cash; // safe even when facts are partially null
  return {
    netDebt,
    minorityInterests: facts.minorityInterest ?? 0,
    preferred: facts.redeemablePreferred ?? 0,
    sharesOutstanding: facts.sharesOutstanding ?? 0,
    period: filing.periodEnd,
  };
```

## Risks / open questions

- **Not a financial methodology change** — the bridge is arithmetic; the user still owns every estimate. No “market data fetch” dependency to slow things down.
- **Tag coverage is a best effort.** SpaceX-specific tags (e.g. `RedeemableConvertiblePreferredStockValue`) differ across filers; when a tag's missing, prefill skips that field (`null`), only filling entries with certainty. The UI’s proposed values state the filing period (periodEnd) so future staleness is visible.
- **B**ig tickers with restated filings may show both reportDate and filingDate confusion — `latestPeriodic` prefills per the same filing the segment reader uses, so they stay consistent.
- Voluntary unknowns: some filers report bridge-relevant figures in different units (thousands/millions); the extraction reads the raw instance XML (always raw dollars), so units are consistent even when presentation differs.
